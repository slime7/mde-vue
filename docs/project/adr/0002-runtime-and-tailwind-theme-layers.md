# 0002 — 采用运行时令牌与 Tailwind 适配双层主题

- 状态: active
- 日期: 2026-07-13
- 替代: 无

## 背景

组件需要根据种子色、亮暗模式、Material 3 配色变体和对比度在运行时变化，同时使用方可能选择原生 CSS 或 Tailwind CSS v4。组件不能依赖某个可选样式框架才能正确显示。

## 决策

以目标 DOM 元素上的 --mat-* CSS 自定义属性作为运行时主题权威值；主题控制器使用 Material Color Utilities 生成颜色令牌。另提供 Tailwind CSS v4 的 @theme inline 适配层，将同一语义映射到带 mat 前缀的 Tailwind 主题变量，不复制具体颜色值。

## 考虑的方案

- 在每个组件中硬编码颜色和状态：实现直接，但无法一致地支持动态配色。
- 只提供 Tailwind 主题：工具类使用方便，但会让组件运行依赖可选框架。
- 预构建有限数量的静态主题文件：无需运行时计算，但不能满足任意种子色和对比度。

## 影响

- 原生 CSS 使用方只导入基础样式，Tailwind 使用方额外导入适配层。
- 新增或重命名语义令牌时必须同步基础令牌、Tailwind 映射、测试和文档。
- 所有 Tailwind 主题变量使用 mat 前缀，避免污染常见变量名。
