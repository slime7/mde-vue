# 0032 — 移除 Tooltip 分组容器，延迟跳过全局生效

- 状态: active
- 日期: 2026-08-16
- 替代: 0031

## 背景

data-mat-tooltip-group 容器协议要求使用方显式标记相关 DOM 祖先，未被标记的 Tooltip 之间无法快速切换，与显示中切换立即显示的全局预期不符。

## 决策

移除 data-mat-tooltip-group 分组容器协议，跳过打开延迟的条件改为模块级当前是否有任意 Tooltip 显示：任一 Tooltip 显示时进入另一个展示元素立即显示；无显示时一律按 openDelay 计时。

## 考虑的方案

- 保留分组容器并仅调整跳过条件：使用方仍需标记容器，未被覆盖的 Tooltip 保持完整延迟，不符合本次需求目标。

## 影响

- 删除分组相关 DOM 协议与 WeakMap 状态，改用模块级活动实例判断；同步更新测试、使用文档、架构说明与 ADR 状态。
