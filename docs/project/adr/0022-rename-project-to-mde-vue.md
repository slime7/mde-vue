# 0022 — 项目更名为 mde-vue

- 状态: active
- 日期: 2026-08-07
- 替代: 无

## 背景

项目原名 mdu-ui，origin 远程仓库已在 GitHub 改名为 mde-vue；包名、ESM 分发文件名、文档标题和安装地址中的项目名称需要与远程仓库保持一致，避免消费方与文档继续引用旧名称和旧仓库地址。

## 决策

除 ADR 历史记录外，将包名改为 mde-vue，单一 ESM 分发产物改为 dist/mde-vue.js，安装文档中的 Git 地址改为 git@github.com:slime7/mde-vue.git，文档、测试与配置中的项目称呼统一为 mde-vue。公共 API（createMatUi、useMatTheme、mat-* 组件等）不变。

## 考虑的方案

- 保留 mdu-ui 名称，仅改远程仓库名：包名与仓库长期不一致，安装说明和文档产生歧义。
- 仅改文档显示名称，保留包名 mdu-ui：消费方继续安装旧包名，仓库与名称错位，不利于后续维护。
- 全面更名为 mde-vue：全仓库使用同一名称，消费方需要同步更新依赖名与安装地址。

## 影响

- 已通过私有 Git 安装 mdu-ui 的消费方需要把依赖名、安装地址与导入语句中的包名改为 mde-vue，组件名与公共 API 不变；历史 ADR 中的 mdu-ui 称呼作为当时决策上下文保留；后续文档与分发产物一律使用 mde-vue。
