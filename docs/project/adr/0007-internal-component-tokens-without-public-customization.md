# 0007 — 保留内部组件令牌但不提供公共定制入口

- 状态: active
- 日期: 2026-07-14
- 替代: 0006

## 背景

ADR 0006 将 reference、system 和 component 三层令牌一并作为公共 CSS 接口。当前四个按钮组件因此需要记录和维护大量按尺寸、变体与状态展开的组件变量，但这些变量主要服务组件内部样式组合，尚无必须向使用方保证兼容性的实际需求。继续公开它们会扩大文档、测试和迁移范围，却不会简化 Vue 组件逻辑。

## 决策

公开 CSS API 保留 `--mat-ref-*` 与 `--mat-sys-*` 参考和系统语义令牌。`--mat-<component>-*`、`--mat-button-*` 及其他组件内部 CSS 自定义属性继续用于组织样式，但不作为公共定制入口，不在组件 API 文档中列出，也不提供名称或行为兼容承诺。组件级定制通过已公开的 Vue props 完成，应用自有样式可使用系统语义令牌。ADR 0006 确立的完整 `size`、`variant` 名称和 Material Expressive 几何值继续保留。

## 考虑的方案

- 继续公开全部组件令牌：使用方可细粒度覆盖，但必须长期维护大量变量、文档和兼容性。
- 删除组件 CSS 自定义属性并内联全部值：减少变量数量，但会增加尺寸、变体和组合状态间的样式重复。
- 只公开少量选定组件令牌：保留部分定制能力，但仍需界定和维护另一套组件级公共接口。

## 影响

- 组件文档和 AI 文档不再列出组件 CSS 定制入口，样式测试也不再把具体组件变量视为公共契约。
- 内部组件变量可以随实现重构而调整，但仍需通过组件行为、视觉状态和构建检查保证组件正确工作。
- 已经直接依赖组件内部变量的使用方需要改用组件 props、系统语义令牌或应用自有样式。
- ADR 0006 被本决策替代；其组件属性完整命名和 Material Expressive 几何决策继续生效。
