# 0017 — 使用应用配置与显式容器协调 Tooltip 延迟

- 状态: superseded
- 日期: 2026-07-31
- 替代: 无

## 背景

应用需要统一设置 Tooltip 首次打开延迟，并只在语义相关的局部控件之间允许快速切换。MatBtn 与 MatFab 会在内部创建 Tooltip，因此仅由使用方逐个传递属性无法完整覆盖。

## 决策

由 createMatUi 的 tooltip 配置提供全局打开延迟和跳过延迟时长；使用方通过 data-mat-tooltip-group 显式标记分组容器；MatTooltip 根据目标最近的分组容器协调延迟。

## 考虑的方案

- 修改 MatTooltip 全局默认值会影响所有使用方且无法区分模块；应用侧包装组件无法覆盖按钮内部 Tooltip；自动推断 DOM 祖先缺少稳定语义。

## 影响

- 组件库增加两个向后兼容的插件选项和一个公开分组标记协议；应用需要明确标记相关容器；未配置或未分组时保持原有行为。
