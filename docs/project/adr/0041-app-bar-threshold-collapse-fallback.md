# 0041 — App bar 关闭时间线时提供阈值折叠回退

- 状态: active
- 日期: 2026-10-30
- 替代: 无

## 背景

0040 将 App bar 的 CSS scroll timeline 改为显式启用。关闭时间线后只保留基础表面过渡会让 flexible 变体始终展开，缺少可感知的折叠反馈。需要在避免逐帧主线程写样式的前提下恢复折叠观感。

## 决策

未启用 scrollTimeline 时，在 flexible 展开区的起始位置放置不可见观察哨，通过 IntersectionObserver 在滚动越过 16px 后切换 data-collapsed；普通 CSS 弹簧过渡负责表面裁剪、标题缩放、内容位移与副标题淡出，回到阈值以内时展开。观察器不可用或滚动源不包含观察哨时，使用被动滚动监听按同一阈值更新状态；启用 scrollTimeline 时继续由连续时间线驱动。

## 考虑的方案

- 关闭时间线后保持静态展开：没有逐帧成本，但丢失 flexible 折叠反馈
- 通过滚动事件逐帧写入折叠进度：可近似连续效果，但重新引入每帧主线程样式工作
- 使用顶部观察哨切换两段式状态并由 CSS 过渡完成：不逐帧读取进度，保留可感知的折叠效果

## 影响

- 默认路径增加一次阈值状态切换和一段普通 CSS 过渡，效果是展开与折叠之间的平滑变化，不随滚动进度连续跟随。
- 时间线仍为显式可选项；观察哨位于内部占位中，不增加可见布局尺寸，并通过 E2E 验证阈值、折叠和回顶展开。
