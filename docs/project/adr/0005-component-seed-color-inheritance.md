# 0005 — 采用组件级种子配色与父子继承

- 状态: active
- 日期: 2026-07-13
- 替代: 无

## 背景

大部分交互组件需要按语义色复用全局令牌，也需要按单个六位十六进制种子色生成局部配色；按钮组和 split button 还需要向子按钮传递统一的尺寸、颜色与禁用状态。

## 决策

按钮族统一提供 color prop；语义字符串引用全局令牌，六位十六进制值生成局部 Material 2025 primary 色族。组合组件通过 Vue 上下文级联，子组件显式值优先，prop 生成的局部变量优先于同名 CSS 定制变量。

## 考虑的方案

- 只允许应用通过 CSS 变量手工覆盖组件颜色。
- 每个组件独立实现配色与继承逻辑。

## 影响

- 组件可以局部换色而不污染全局或兄弟节点，组合组件保持一致配色。
- 运行时需要缓存局部配色，并要求后续公共组件遵守相同的 color 格式、角色映射和优先级。
