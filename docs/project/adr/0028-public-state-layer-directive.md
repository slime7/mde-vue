# 0028 — 公共 State layer 指令统一交互状态层

- 状态: active
- 日期: 2026-08-13
- 替代: 无

## 背景

组件内部存在重复状态层与按压保持实现，使用方也需要在自定义交互元素上复用相同视觉状态。

## 决策

公开对象绑定的 `v-state-layer` 指令，以内部 DOM 状态层、CSS Anchor Positioning 和统一按压保持实现 hover、focus-visible 与 pressed；`MatActionBase` 复用同一指令。该决策延续 ADR 0008 的 Action 复用方向，但把通用视觉状态与按压生命周期下沉为组件和使用方均可使用的公共指令。

## 考虑的方案

- 继续在各组件中维护伪元素与按压逻辑
- 公开基础 Action 组件而不提供指令

## 影响

- 状态视觉与按压生命周期只有一份实现；宿主必须能容纳内部子元素，内部节点和属性不属于公共接口。
- 对象绑定首版只公开可选 `color`，为后续增加独立选项保留稳定调用形式。
- 状态层使用宿主自身作为 CSS anchor，不占用宿主的伪元素或普通定位上下文。
