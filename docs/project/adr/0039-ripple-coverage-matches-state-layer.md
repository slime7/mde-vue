# 0039 — 涟漪覆盖范围与状态层对齐

- 状态: active
- 日期: 2026-10-29
- 替代: 无

## 背景

全局涟漪启用后，导航项、多操作列表项和 secondary 标签页的可见状态层只覆盖图标指示器、整行表面或内缩矩形，而 v-ripple 仍以宿主全框绘制，造成涟漪超出状态层范围。

## 决策

v-ripple 新增 target 选项，用 CSS Anchor Positioning 把涟漪容器锚定到目标元素，并以容器实际矩形计算波纹起点、半径与裁剪；组件通过内部 --mat-ripple-inset、--mat-ripple-radius 变量表达内缩与圆角。导航项把 target 指向图标指示器，多操作列表项把涟漪移到承载可见状态层的整行，secondary 标签页复用状态层的内缩与圆角变量。目标模式的圆角在每次按压前从目标元素同步，避免固定圆角与目标形状不一致。

## 考虑的方案

- 为每个组件分别叠加裁剪或遮罩，保持涟漪仍以宿主为几何基准
- 扩展 v-ripple target 选项并统一以实际涟漪容器为几何基准
- 把涟漪指令直接挂到可见状态层元素上

## 影响

- 涟漪与状态层范围由同一几何源决定，自定义组件的状态层也能复用 target；涟漪容器仍挂在宿主上，不改变组件的交互 DOM 语义。target 必须能提供布局矩形，非法值回退宿主。
