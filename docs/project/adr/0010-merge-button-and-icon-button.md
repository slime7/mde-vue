# 0010 — 合并普通按钮与图标按钮公共接口

- 状态: active
- 日期: 2026-07-15
- 替代: 无

## 背景

普通按钮与图标按钮已经共享原生按钮基础层、状态模型和组合上下文，但仍公开两套组件、入口、模板标签、样式和文档，增加了组合组件适配与使用成本。

## 决策

只保留 MatBtn 与 mat-btn；非空 icon 字符串切换图标模式，prefix 和 suffix 提供普通按钮前后图标，移除 MatIconBtn、mat-icon-btn 及其单组件入口。

## 考虑的方案

- 保留两个公共组件，只继续抽取内部样式与模板。
- 保留 MatIconBtn 作为兼容包装器并逐步迁移。

## 影响

- 公共按钮接口和组合组件识别逻辑统一，后续只维护一套实现、测试和文档。
- 这是不兼容变更，现有使用方必须迁移标签、导入和图标内容写法。
