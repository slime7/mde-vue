# 0001 — 通过私有 Git 直接分发源码

- 状态: active
- 日期: 2026-07-13
- 替代: 无

## 背景

项目只供仓库所有者在 Vue 3 应用中使用，不发布到 npm。使用方的 Vue/Vite 构建过程能够直接编译 JavaScript、Vue SFC 和 CSS，因此没有维护公开发布产物与版本渠道的必要。

## 决策

将 package 标记为 private，通过 package exports 暴露源码入口、单组件入口和样式入口；使用方通过私有 Git SSH 地址固定到具体提交安装。不提交 dist，也不配置 prepare 或 npm 发布流程。

## 考虑的方案

- 发布编译后的 npm 私有包：提供传统版本和产物边界，但增加发布凭据、版本和制品维护成本。
- 在仓库提交 dist 后从 Git 安装：使用方构建要求较低，但源码与产物容易不同步。
- 在使用方项目间复制组件源码：无需包配置，但修复和接口会快速分叉。

## 影响

- 仓库只维护源码和公开 exports，构建检查必须从这些入口验证普通 Vue/Vite 项目可以编译。
- 使用方需要具备 Vue SFC 和 CSS 构建能力，并显式导入基础样式。
- 安装说明必须使用固定提交，避免分支移动导致不可重复安装。
