# 0029 — 采用稳定的 mde CSS 级联层

- 状态: active
- 日期: 2026-08-14
- 替代: 无

## 背景

组件库样式此前未进入命名级联层，使用方覆盖组件样式时依赖选择器权重，且源码开发态与分发产物缺少稳定的层序契约。

## 决策

`styles.css` 公开固定层序 `mde.tokens`、`mde.components`、`mde.utilities`。基础令牌、组件样式和公共排版工具类分别进入对应层，所有 SFC 源码样式直接进入 `mde.components`，使开发态与分发态保持一致。未分层应用样式自然优先；独立的 `tailwind.css` 不进入 `mde` 层。

## 考虑的方案

- 单一 `mde` 层：接口简单，但无法分别排序令牌、组件和公共工具类。
- 按组件细分层：控制精细，但公开层名数量和维护成本过高。

## 影响

- 使用方可以依赖稳定层名定向排序或覆盖，普通未分层 CSS 默认覆盖库样式。
- 新增公共样式必须归入对应层，组件源码和构建产物需保持相同层叠行为。
- Tailwind 映射继续遵循 Tailwind CSS v4 自身的编译与层序规则。
