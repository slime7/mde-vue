# 0011 — 采用共享 Dialog 宿主与关闭后 Promise 结算

- 状态: active
- 日期: 2026-07-15
- 替代: 无

## 背景

Dialog 既要提供受控 Vue 组件，也要提供可并行调用的 dialog、alert、confirm 和 prompt 函数。命令式实例需要复用组件行为、插件图标与主题配置，并避免在退出动画完成前移除 DOM。

## 决策

命令式函数使用 Vue render 创建一次性宿主，宿主渲染同一个 MatDialog，并通过模块级的最后安装插件上下文提供组件设置和主题控制器。所有正常取消均返回约定值，Promise 只在退出动画完成、原生 dialog 关闭且宿主 DOM 清理后结算。多个实例通过共享堆叠管理器协调顶层帷幕。

## 考虑的方案

- 在应用模板中要求使用者自行挂载统一 Dialog 服务容器；上下文最明确，但快速函数需要额外安装步骤。
- 命令式函数独立拼装原生 DOM；创建简单，但会复制组件结构、样式、焦点和动画逻辑。

## 影响

- 组件与命令式入口共享同一套行为、测试和 Material 3 样式。
- 多应用场景采用最后安装的插件配置，调用方需避免依赖不同应用的并行全局配置。
- 正常取消不会产生 rejected Promise；参数、目标或客户端环境错误仍明确拒绝。
